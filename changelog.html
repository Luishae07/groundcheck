Changelog

What's changed in Groundcheck, most recent first.

October 15, 2026

Added an all-time visit counter to the footer. A page announces itself once over the live-feed WebSocket and the total is kept in a plain text file. No IP address or ID is stored
Added "Projects we make" to the Credits tab, with a link to Flowsearch
The site is now also served at the root, luishae07.github.io
Search engines and AI assistants: better title, description and social tags, a real heading, an About text in the page itself, and new llms.txt, robots.txt and sitemap files
Unwanted scrapers now get HTTP 402 Payment Required on our server

October 14, 2026

An approximate location from your IP address is now looked up on our own server with the DB-IP database, instead of an outside service
Much faster data loading: the common time ranges are kept ready in server memory, and a half-written data file can no longer break the site
The MCP forecast tool now takes a latitude and longitude and returns the full forecast, and says so when there is no balloon data nearby
Firefox add-on 1.0.1 is live: it only shows readings from the last 19 hours
Removed the status page. The Wall display now loads its readings through the tunnel

October 13, 2026

The forecast now works worldwide: more history, a model for places with few readings, and a search radius that widens up to 900 km
NOAA data now covers the last 300 days

October 12, 2026

Added NOAA IGRA data: ground-level readings from about 750 weather-service stations around the world

Early October 2026

New design in the style of Apple Weather, for mobile and desktop, with tiles that show dials and rings
Added a Credits tab, a new logo and the official Get the add-on card for Firefox
SondeHub data is now fetched every 5 hours, gently
Added a lean data API, so pages load only the days they show
New standalone API documentation for Groundcheck
Added a 3D globe of every reading ever (coolthing.html)
Forecasts are built only from balloon readings, with no outside forecast service

September 10, 2026

Native SwiftUI iOS app, built via GitHub Actions
Fixed temperature heatmap: was rendering invisibly under the map, and extrapolating full color into areas with no real station coverage
Replaced blob-style heatmap with a true full-coverage interpolated surface, matching the Apple Weather map style

September 9, 2026

Added temperature heatmap map mode
Added Go-based status page checking every live component
Added Wall display — a fullscreen kiosk mode with GPS-aware location and auto-cycling slides
Added Search to mobile view
Renamed "Next hours" predictor to "Next days," added it to desktop
Added native macOS app (Swift/WebKit wrapper)
Added MCP server to the self-host backend package

September 8, 2026

Self-host backend package now interactively bootstraps data and schedules updates
start.ps1 detects WSL and offers to delegate to start.sh

September 7, 2026

Added standalone self-host backend package with cross-platform start scripts

September 6, 2026

Added "This day" map filter option
Added date-range control to Search (7/30/90 days, or all time)
Search results now show on their own satellite map
Added universal Search: station ID, temperature value, or place name
Added Account tab — local nickname + token, device-only, no server accounts
Added a pulsing "you are here" marker once your location is known
Added native Kotlin/Compose Android app with a real map, predictor, and live feed
Added next-hours predictor (from a 7-day diurnal pattern)

September 5, 2026

Deployed the static site to GitHub Pages
