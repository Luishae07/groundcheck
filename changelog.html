Changelog

What's changed in Groundcheck, most recent first.

September 10, 2026

Native SwiftUI iOS app, built via GitHub Actions
Fixed temperature heatmap: was rendering invisibly under the map, and extrapolating full color into areas with no real station coverage
Replaced blob-style heatmap with a true full-coverage interpolated surface, matching the Apple Weather map style

September 9, 2026

Added temperature heatmap map mode
Added Go-based status page checking every live component
Added Wall display — a fullscreen kiosk mode with GPS-aware location and auto-cycling slides
Added Search to mobile view
Renamed "Next hours" predictor to "Next days," added it to desktop
Added native macOS app (Swift/WebKit wrapper)
Added MCP server to the self-host backend package

September 8, 2026

Self-host backend package now interactively bootstraps data and schedules updates
start.ps1 detects WSL and offers to delegate to start.sh

September 7, 2026

Added standalone self-host backend package with cross-platform start scripts

September 6, 2026

Added "This day" map filter option
Added date-range control to Search (7/30/90 days, or all time)
Search results now show on their own satellite map
Added universal Search: station ID, temperature value, or place name
Added Account tab — local nickname + token, device-only, no server accounts
Added a pulsing "you are here" marker once your location is known
Added native Kotlin/Compose Android app with a real map, predictor, and live feed
Added next-hours predictor (from a 7-day diurnal pattern)

September 5, 2026

Deployed the static site to GitHub Pages
