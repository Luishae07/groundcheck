Get an API key

A free key for the Groundcheck data API. Press the button, copy the key, and use it in your requests.

1. Create your key

Without a key the API allows 30 requests per minute. A key allows far more, and it does not expire.

2. Copy it and keep it

This page does not save the key and cannot show it again. Anyone who has it uses your limit, so do not share it.

3. Use it

Put it at the end of the data address:

Or send it in a header named X-API-Key. To see how much a key is used, open the key page. The full list of requests is in the API docs.
