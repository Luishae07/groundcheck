Self-host Groundcheck for almost nothing

Groundcheck's server is one small Python program. No database, no Docker, no extra packages. It runs on nearly anything, so the real question is only: what is the cheapest machine you can leave switched on?

Why it must stay on. The weather-balloon source only hands out the latest reading of each balloon. Groundcheck builds its history by asking every minute, and it catches balloons just after launch or landing that way. A computer that sleeps or is switched off misses them. So "cheapest" really means "cheapest thing that is on all day".

What it needs

  • Python 3 (nothing else to install).
  • 512 MB of memory and 1 GB of disk are plenty.
  • A normal internet connection. It makes one small request a minute.

Set it up (about five minutes)

On the machine you picked, in a terminal:

curl -L -o groundcheck.zip https://github.com/Luishae07/groundcheck/archive/refs/heads/main.zip
python3 -m zipfile -e groundcheck.zip .
cd groundcheck-main/backend
bash start.sh

The second line unpacks the download with Python itself, so you don't need unzip, tar or git. start.sh then asks a few questions. These answers give the cheapest, always-up-to-date setup:

QuestionAnswer
HTTP data API portPress Enter (8765)
WebSocket live-feed portPress Enter (8766)
Max ground-level altitude filterPress Enter (980)
Create data.json now?y, then choose how many days of history to fetch, for example 10
Set up automatic checks with cron?y
Check every minute?y
Also check once daily?y
Run in the background with nohup?y
Enable logs?y

Then open http://localhost:8765/ (or the machine's address from another device on your network). The cron job keeps adding new readings; the more days it runs, the fuller the history.

Keep it running after a restart

The cron job restarts the updates by itself. The web server also needs to start when the machine boots. Run crontab -e and add two lines (change the folder to where you unpacked it):

@reboot cd /home/pi/groundcheck-main/backend && nohup python3 serve.py >/dev/null 2>&1 &
@reboot cd /home/pi/groundcheck-main/backend && nohup python3 ws_proxy.py >/dev/null 2>&1 &

The cheapest sensible plan

  1. Use a Raspberry Pi you already have, or an old laptop, as the always-on machine. About €20–60 if you have to buy one.
  2. Run the four commands above and answer y to cron every minute.
  3. Add the two @reboot lines.
  4. Leave it on your home network, or add a free Cloudflare quick tunnel when you want to show it to someone.
Running cost afterwards: a few euros of electricity a year. If you don't want any hardware, a free cloud tier or a €3–5 a month VPS does the same job.

Questions

Does it cost anything per visit? No. It only serves one small data file, and there are no accounts or databases to pay for.

Can I run it on a phone? Yes, on Android with Termux. An iPhone app can run it only while the app is open on screen, so it's no good for a server.

I only want to see the data, not host it. You don't need any of this. The hosted Groundcheck app and the apps for iPhone, Android and desktop are free to use.

Is it safe to put on the internet? It only serves public weather-balloon readings and has no login. Keep Python and the machine updated, and prefer a tunnel over opening your router.
