Groundcheck API

Read-only endpoints backing the Groundcheck weather app — real radiosonde ground-temperature readings, with a free optional API key for a much higher rate limit.

Endpoints

GET/api/data
All current non-negative-temperature radiosonde readings, sorted newest first. Without an API key, limited to 30 requests per 60 seconds per IP. With a key, 9000 requests per 10 seconds. Exceeding your limit returns 429 with a Retry-After header.
POST/api/keys/new
Generates a free API key on the spot — no signup. Returns {"api_key": "...", "limit": "9000 requests / 10s"}.
GET/weather_data_nonneg.txt
The same readings as a plain-text line list, one reading per line.

Using an API key

Get one:

curl -X POST http://localhost:8765/api/keys/new

Then pass it on every request, either as a header or a query parameter:

curl http://localhost:8765/api/data -H "X-API-Key: <your key>"

curl "http://localhost:8765/api/data?key=<your key>"

Response shape (/api/data)

An array of reading objects:

[
  {
    "id": "Y0943402",           // radiosonde serial number
    "time": "2026-09-05T04:57:35Z",
    "tsunix": 1788584255,
    "temp": 12.7,               // °C, ground-level (negatives filtered out)
    "alt": 474.91,              // metres
    "pressure": 959.8,          // hPa, or null if unavailable
    "humidity": 90,             // %, or null if unavailable
    "lat": 51.772308,
    "lon": 9.25355,
    "source": ["RS41"]          // sonde model / receiver tag
  },
  ...
]

Fields

FieldTypeNotes
idstringUnique sonde serial number
timestring (ISO 8601, UTC)When the reading was taken
tsunixnumberSame timestamp, Unix seconds
tempnumberGround temperature in °C — always ≥ 0 in this feed
altnumberAltitude in metres
pressurenumber | nullBarometric pressure in hPa
humiditynumber | nullRelative humidity, %
lat / lonnumberWGS84 coordinates
sourcestring[] | nullReceiving station / sonde model tags

Notes

Data originates from sonde.mine.nu's live radiosonde telemetry feed. Readings with sub-zero temperatures (typical at flight altitude) are excluded, since they aren't representative of ground weather. The underlying data refreshes on a schedule — see the app's FAQ for details.

An API key is optional, not required — without one you get the default rate limit; with one, the much higher limit described above.
